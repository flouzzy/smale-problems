# Contribuer au Programme de Recherche sur les Problèmes de Smale

Nous accueillons les contributions relatives à la formalisation et à l'analyse des **18 Problèmes de Smale**.

## Standards Requis :
1. **Style Académique Terence Tao** : Démonstrations sans ellipse, structure monographique pédagogique, typographie LaTeX soignée.
2. **Vérification Formelle Lean 4** : Tout code doit compiler avec 0 `sorry`, 0 axiome et 0 avertissement de linter sous `lake env lean <fichier>.lean`.
3. **Préparation Zenodo** : Chaque dossier de preprint doit inclure un fichier `presentation.md` avec métadonnées HTML/Markdown pour le dépôt.
