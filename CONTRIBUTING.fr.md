# Contribuer au Programme de Recherche sur les Problèmes de Smale

Les contributions à la formalisation et à l'analyse des **18 Problèmes de Smale** sont les bienvenues.

## Standards :
1. **Rigueur Académique & Pédagogie** : Démonstrations pas-à-pas sans ellipse, structure monographique approfondie, typographie LaTeX soignée.
2. **Vérification Formelle Lean 4** : Tout le code doit être vérifié avec 0 `sorry`, 0 axiome et 0 avertissement du linter via `lake env lean <fichier>.lean`.
3. **Préparation Zenodo** : Chaque dossier de prépublication doit contenir un fichier `presentation.md` avec métadonnées HTML/Markdown prêtes au dépôt.
