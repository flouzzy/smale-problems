# Smale Problem #09: The Linear Programming Problem

## Problem Formulation
Is there a strongly polynomial-time algorithm for linear programming?

## Mathematical Context
Khachiyan (1979) and Karmarkar (1984) proved LP is weakly polynomial (complexity depends on bit-length L). Smale asks whether the number of arithmetic operations can be bounded solely by a polynomial in the matrix dimensions m and n.

## Research Directions & Open Leads
Interior-point central path curvature bounds, Strongly polynomial algorithms for combinatorial matrices (Tardos), Tropical geometry approaches.
