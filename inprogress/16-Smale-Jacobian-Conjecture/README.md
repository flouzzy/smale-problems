# Smale Problem #16: The Jacobian Conjecture

## Problem Formulation
If F: C^n → C^n is a polynomial map with non-zero constant Jacobian determinant det(Jac F) ∈ C^*, is F an invertible polynomial automorphism (with polynomial inverse)?

## Mathematical Context
Formulated by Ott-Heinrich Keller (1939). In 2005, Tsuchimoto and Belov-Kanel/Kontsevich proved that the Jacobian Conjecture is stably equivalent to the Dixmier Conjecture on Weyl algebras.

## Research Directions & Open Leads
Dixmier conjecture equivalence, Poisson algebras, Tropical geometry, Reduction to degree 3 (Bass-Connell-Wright, Yagzhev).
