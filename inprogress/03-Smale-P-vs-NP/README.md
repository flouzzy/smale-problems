# Smale Problem #03: P versus NP Problem (Millennium Prize Problem #3)

## Problem Formulation
Does P equal NP? That is, can every algorithmic problem whose solution can be verified in polynomial time also be solved in polynomial time?

## Mathematical Context
Formulated by Stephen Cook (1971) and Leonid Levin (1973). Smale listed this as Problem 3 in the BSS (Blum-Shub-Smale) real and complex algebraic computation models as well as the Turing model.

## Research Directions & Open Leads
Natural Proofs barrier (Razborov-Rudich), Algebrization (Aaronson-Wigderson), Relativization (Baker-Gill-Solovay), Geometric Complexity Theory (Mulmuley-Sohoni).
