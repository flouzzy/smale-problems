# Contributing to Smale Problems Research Program

We welcome contributions to the formalization and analysis of the **18 Smale Problems**.

## Standards:
1. **Academic Rigor & Pedagogy**: Non-elliptical proofs, deep pedagogical monographs, clean LaTeX listings.
2. **Lean 4 Formal Verification**: All code must verify with 0 `sorry`, 0 axioms, and 0 linter warnings under `lake env lean <file>.lean`.
3. **Zenodo Preparation**: Each preprint directory must contain a `presentation.md` file with rich HTML/Markdown metadata.
